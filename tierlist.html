METHODOLOGY

HOW THE TIER LIST IS GENERATED

STATISTICAL MODEL

Every weapon receives a custom Analyzer Score based on selected attributes stored in the Apex//Analyzer database.

SCORE INPUTS

The current model evaluates body damage, rounds per minute and Level III magazine capacity.

TIER THRESHOLDS

  • S Tier: 9–10 points
  • A Tier: 7–8 points
  • B Tier: 5–6 points
  • C Tier: 0–4 points

MODEL LIMITATIONS

The current score does not yet account for recoil, reload time, projectile speed, attachments, range, accuracy or weapon-class-specific behavior.

The Analyzer Tier List is an experimental statistical model. It is not an official Electronic Arts or Respawn Entertainment ranking.
